# 00A evidence audit — 2026-09-19

## Decision

00A is **개발중**. 00B remains **선행작업 대기**. Passing unit tests do not establish a durable backend or tool gateway selection.

The current gate-by-gate status is in [00A live gate matrix](00a-live-gate-matrix.md).

The local live lab launcher is `scripts/run_00a_live.sh`. It requires the two named PostgreSQL test databases, starts a disposable Restate server, probe worker, three MCP upstreams and LiteLLM, runs pytest, then stops its processes. The backend outage tests still require their separate destructive opt-ins.
